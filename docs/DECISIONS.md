# Decisiones

## Versiones reproducibles

Se fijan versiones explícitas de Pinot, Kafka y ZooKeeper en lugar de usar etiquetas `latest`, evitando que una actualización futura cambie la práctica.

## Datos de prueba

Se utiliza el conjunto `airlineStats` incluido en la imagen oficial de Pinot. Esto permite demostrar el flujo completo sin depender de servicios externos.
