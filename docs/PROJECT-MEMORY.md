# Memoria del proyecto

## Estado actual

Entrega académica LG14 basada en Apache Pinot. El objetivo es desplegar con Docker Compose un flujo de eventos de vuelos desde Kafka hacia Pinot y demostrar consultas OLAP en tiempo real.

## Fuente

- Repositorio: `https://github.com/apache/pinot`
- Organización: Apache Software Foundation
- Commit inspeccionado: `7a00b2318bee93bb6de8bc8538685fab76cc3c95`
- Receta base: `docker/images/pinot/docker-compose.yml`

## Entregable

Repositorio público con README sencillo, configuración reproducible, scripts, diagrama, comparación con Hadoop y evidencias reales.
